# Phase III - Task 2: PySide6 Timer App

A PySide6 countdown timer implementing:
- QLineEdit input in seconds
- QIntValidator input validation
- QStackedWidget input/timer views
- Start/Pause/Resume behavior
- Reset behavior
- MM:SS countdown display
- Automatic reset when the timer reaches 00:00

## Run

```bash
pip install -r requirements.txt
python -m timer_app
```

If running from the repository root, use:

```bash
PYTHONPATH=src python -m timer_app
```
